# Data Preprocessing — Saving Per-Minute Features

This folder contains the scripts that **load, clean, align, and save** per-minute wearable features + HRV features into a single CSV per **(participant, day)**.

The main entry point for saving features is:

- `save_features.py`

Supporting modules:

- `config.py` — dataset paths + feature/HRV definitions
- `data_cleaning.py` — loading + cleaning logic (ignore conditions, timestamp→minute indexing)
- `utils.py` — time conversion helpers (e.g., `convert_to_minutes`, `compute_day_str`)

---

## Output

For each `(pid, day)` the script writes:

- `processed_data_all/<pid>-<day>-features.csv`

Each output CSV contains:

- `Time Index` (0 … `NUM_TIME_SAMPLES-1`)
- `Timestamp` (`HH:MM`)
- all wearable features in `FEATURE_DICT_LIST`
- all HRV features in `HRV_NAME_LIST`

A log file is also created in:

- `log/feature_log_<timestamp>.txt`

---

## 1) Set the required variables

### A) `config.py` (must be set correctly)

Open `config.py` and set:

#### Dataset selector
- `dataset_country = 'c1'`  # must be `'c1'` or `'c2'`

#### Paths
- `ROOT_FOLDER`  
  Points to the root data directory. The following paths are derived from it:
  - `FEATURE_FOLDER = ROOT_FOLDER/rawdata_<dataset_country>`
  - `HRV_FOLDER = ROOT_FOLDER/hrv_indices`
  - `DATES_CSV = ROOT_FOLDER/<dataset_country>_start_end_dates.csv`
  - `SAVE_FOLDER = ROOT_FOLDER/processed_data_all`
  - `HRV_CSV = 'hrv_indices.csv'` (file name inside each pid/day folder)

#### Time axis / missing values
- `NUM_TIME_SAMPLES = 1440` (per-minute samples for 24h)
- `MISSING_MARKER = -200` (converted to `NaN` during cleaning)

#### Feature definitions
- `FEATURE_DICT_LIST` controls:
  - which CSV file(s) to read per feature (`csv_list`)
  - which Source values to filter on (`source_list`)
  - ignore rules (`ign_cond`) used to convert out-of-range values to `NaN`

- `HRV_NAME_LIST` is the ordered list of HRV columns read from the HRV CSV.

## Additional operation (C2 only): Fill missing Step Count / Total Count using intraday.csv

For the **C2** dataset, some participants have an **empty** `step-log.csv`. In those cases, we compute step-derived columns using the **15-minute intraday summaries** and write them back into the already-saved per-minute feature CSVs.

**Script:** `update_step_log_using_intraday.py`

**What it does:**
- Reads `intraday.csv` (15-min windows with `Start Time (Local)`, `End Time (Local)`, and `Steps`)
- Converts each 15-min interval into **per-minute Step Count** by distributing steps across minutes
- Updates the saved file:
  - `Step Count` (per-minute steps)
  - `Total Count` (cumulative sum of Step Count)

**When to run:**
1) Run `save_features.py` first (creates `<pid>-<day>-features.csv`)
2) Then run `update_step_log_using_intraday.py`

## Additional operation: Create sleep-only feature files (for sleep-specific feature extraction)

Sleep windows are extracted **separately** (from the already-saved per-minute feature CSVs) so that downstream dataset creation can work with **sleep-only segments**, including sleep that **spans midnight** (i.e., starts on `dXX` and ends on `dXX+1`).

**Script:** `save_sleep_features.py`

### What it reads

1) **Per-minute full-day features** (generated by `save_features.py`)
2) **Sleep summary file** (path set in `config.py` as `SLEEP_SUMMARY_CSV`)

This CSV must contain (column names as used in code):
- `PID`
- `Wake Day`  (e.g., `d01`, `d02`, ...)
- `start_time` (timestamp string, format `YYYY/MM/DD HH:MM:SS`)
- `end_time`   (timestamp string, format `YYYY/MM/DD HH:MM:SS`)

3) **Dates mapping** (`DATES_CSV`) to resolve day/date relationships.

### Required variables (in `config.py`)

Make sure these are set in `config.py`:
- `SLEEP_SUMMARY_CSV` (path to sleep summary csv)
- `SLEEP_SAVE_FOLDER` (output folder for sleep-only feature csvs)
- `SAVE_FOLDER` (used as PROCESSED_DATA_FOLDER)
- `DATES_CSV`
- `NUM_TIME_SAMPLES = 1440`
